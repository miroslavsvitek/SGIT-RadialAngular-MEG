# Public analysis map

The manuscript does **not** use the historical internal labels that appear in some archived filenames. The public-facing analysis sequence is:

1. `01_primary_confirmatory_reliability.py` - prospective participant-level confirmation of FULL/AP/AMP RDM reliability.
2. `02_robustness_and_negative_controls.py` - coordinate, prestimulus, metric, and initial phase-randomization controls.
3. `03_radial_angular_component_decomposition.py` - ENERGY, PRODUCT, INTERFERENCE, and ANGLE decomposition.
4. `04_amplitude_preserving_phase_null.py` - direct category-phase null for INTERFERENCE and ANGLE.

The original script names are retained alongside these public-facing copies only to preserve exact historical provenance and checksums.
